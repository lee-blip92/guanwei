# 评论观点与产品洞察 V2 验收记录

日期：2026-10-30。本次在既有中文工作台中实现多维度评论理解、观点归并、程序统计和证据报告，保留七平台接入及旧报告兼容。

## 已实现

- 身份去重仍为平台＋评论 ID；同文不同 ID 保留并提示，不将相似体验当重复用户删掉。
- 一评多观点：每个关注点独立判断产品归属、态度、类型、关键词、痛点、场景、后果与诉求。缺失字段留空。
- 分批初提取与独立复核分别缓存；纯公告、社交、求提醒与产品体验区分；短附和有父评论引用，比较评论按观点归属。
- 带实际原文例子的具体话题归并；不引入英文向量模型，不强制固定主题数。
- 关注点、关键词、正负面、痛点、满意点和需求均由程序按唯一评论 ID 统计；一评可多维度，比例合计可超 100%。
- 逐话题建议与验证方案、整体发现、证据 ID 与字面原文检查；生成段落不合格时明确省略并标部分完成。
- 页面展开证据、逐观点人工修正、排除恢复、Markdown/CSV/打印 HTML/JSON 导出。
- 报告失效前保存版本快照；离线重算不会调用模型，只保留引用全部未变化的旧文案。父评论排除后，其依赖附和暂不纳入。

## 局限与待验证

- HTTP 402 通常为余额或计费额度不足；具体账户原因需用户在提供商后台核查。恢复后可主动选择重新生成；不要把离线复用当成本轮 AI 成功。
- 未取得独立人工标注集，不报告准确率、召回率、节省时间或业务收益。已生成 9 条空白分层核查模板，尚未填写金标。
- 仍可能有相近关注点/话题分散（例如额度消耗、Token 消耗）、用户资讯/提问归类不稳、归属及建议过度推断。离线恢复为保守起见不会重新语义归并或新生成建议。
- 2 条笔记的样本高度受当前讨论事件影响，不能代表 Codex 全部体验；话题频次不代表独立用户数或产品优先级。
- 未做万级以上模型吞吐、超大导入、真实浏览器打印成 PDF 的验收；已有打印 HTML，可由用户浏览器另存为 PDF。未额外新增平台真实登录采集验证。
