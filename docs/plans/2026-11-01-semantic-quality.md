# 语义理解与核心议题质量改进

目标：保留现有 V3 报告与导出，修复上游跨问题归并、不可比证据、字段重复与来源错配。使用现有 SQLite 阶段缓存、模型客户端与后台任务，不增加向量库/服务。

1. 增加逐观点任务结构：评价对象、用户任务、障碍/表现、预期结果、规范场景、各字段原文依据；不确定保留待复核，原 V2 分析保留。
2. 动态议题注册与成员独立复核，按任务/对象/障碍定义归并；新增有意义议题不受旧40类上限限制；复核不符则拆分/待确认。正反观点另做可比性核查。
3. 清除重复或没有直接后果支撑的字段；所有聚合字段保留源观点/评论ID。叙述输入与允许引用采用同一证据集合。失败结论仅在有界改写并再次校验通过后发布。
4. 增加四因素研究优先级、共性/风险/优势摘要和质量覆盖指标。统计分母、筛选主原因保持互斥，业务排期未知。
5. 固定真实评论回归集和人工标签接口；自动协议回归与语义人工准确率分开。备份现有任务后重跑，记录前后具体差异，不宣称未经标注的准确率。
6. 旧报告/旧协议继续可读取，新的语义版本与缓存独立。离线重算复用经过验证且依赖未变的语义结果，不产生新语义判断。
